# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.8.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security issues privately to **hello@clivern.com**. Include steps to reproduce, affected versions, and impact if known.

We will acknowledge receipt and aim to respond with next steps within a reasonable timeframe. If the report is accepted, we will coordinate a fix and disclosure timeline with you. If declined, we will explain why.

Do not open public GitHub issues for undisclosed security vulnerabilities.
